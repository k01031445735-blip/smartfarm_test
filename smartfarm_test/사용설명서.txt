[간편 실행 방법]
1. 이 ZIP 파일의 압축을 한 폴더에 모두 풉니다.
   (폴더 안에 app.py, 24_생육정보.csv, 24_환경정보.csv, 실행하기.bat 파일이 함께 있어야 합니다.)
2. Windows 사용자: '실행하기.bat' 파일을 더블클릭하면 자동으로 패키지가 설치되고 브라우저에 대시보드가 열립니다.
3. Mac/Linux 사용자 또는 터미널 실행: 해당 폴더에서 'streamlit run app.py' 를 입력합니다.
4. 측정값 컬럼을 '측정데이터'로 변경
5. 환경 항목명 컬럼 점검:환경 항목명 확인.환경 항목명 컬럼이 단체표준항목명으로 되어 있는데, 한글 항목명(내부온도, 내부습도, 내부CO2 등)으로 보려면 항목명으로 변경하는 것이 좋습니다.
6. 분석할 생육 지표 컬럼 변경:생육 데이터 컬럼.오른쪽 생육 데이터 컬럼 아래 분석할 생육 지표(한 번에 하나씩 분석)가 측정라인으로 되어 있으므로 조사항목값(또는 생육 지표가 담긴 컬럼)으로 선택합니다.
